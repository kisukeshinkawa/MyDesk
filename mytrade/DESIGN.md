> **v8追記（実装済み・v339）: ネット上のプロ手法を「プロのチェックリスト」として統合**
> 出典（Web調査で収集したコンセンサス）:
> - **ミネルヴィニ「トレンドテンプレート」8条件**: 株価>150/200日線、150>200日線、200日線が1ヶ月以上上向き、50>150>200日線、株価>50日線、52週安値+30%以上、52週高値から25%以内、相対力（3ヶ月対指数の簡易版で代替）
> - **オニール「CAN-SLIM」定量化可能項目**: C=四半期EPS成長+20%以上 / A=年間EPS成長+25%かつROE17%以上 / N=新高値圏（52週高値まで5%以内）/ I=機関投資家保有30%以上（データある時のみ）/ M=地合い（指数200日線上）
> - **25日線乖離率±10%**（国内証券各社の過熱/底値目安）
> - **リスクリワード2:1ルール**: AI判定のシステムプロンプトに「利確幅÷損切り幅が2倍未満なら買い判定禁止」を追加（勝率4割でも資産が増える設計）
>
> チェックリストは銘柄詳細に✅/❌/➖で表示（合格数バッジ付き）。**100点スコアには混ぜない**（バックテスト検証済みの因子構成を崩さないため）。AI判定プロンプトには全項目が注入され、「トレンドテンプレート不合格の銘柄への強気判定は慎重に」と指示。

> **v7追記（実装済み・v338）: EPS/ROEの複数年評価・ローソク足・完全自動学習**
> - **年次EPS・ROE推移**（yfinance年次財務・最大4年）を取得し長期スコアを強化:
>   - 成長性: 「EPSが全期連続増加」を単年成長率より優先評価（EPS=1株利益は増資希薄化・自社株買いを織り込んだ投資家の実質的な取り分）
>   - 収益性: 「ROE 10%以上を複数年安定維持」を水準の高さと同格評価
>   - AI判定プロンプトにもEPS/ROE推移を年次で注入、詳細画面にも推移を表示
> - **ローソク足チャート＋出来高バー**（60日・SVG自前）: 陽線陰線・ヒゲ・出来高の勢いが読める。旧Lambda応答時は線チャートにフォールバック
> - **完全自動学習**: 朝レポート実行時に毎朝答え合わせ（evaluate）を自動実行、JST月曜朝は週次学習（重み最適化＋教訓更新）まで無人実行 → EventBridge1本で「日々精度が上がる」状態に
> - **外部リサーチリンク**: 日本株=Yahoo!ファイナンス/株探/みんかぶ/IR BANK、米株=Yahoo Finance/TradingView/Finviz へワンタップ
> - バグ修正: 地合いフィルタ発動時（指数200日線割れ）の予測記録でゼロ除算が起きる問題

> **v6追記（実装済み・v337）: 資金管理とポートフォリオ運用 — これで打ち止め**
> - **推奨ロット計算(2%ルール)**: 資金×許容リスク(1〜3%)÷損切り幅(2ATR)で株数を自動算出。日本株は単元株(100株)に丸め。値がさ株で1単元がリスク超過なら警告
> - **ポートフォリオ全体ビュー**: 評価額・評価損益・セクター配分を常時表示。セクター50%超/1銘柄40%超の集中警告、保有銘柄間の日次リターン相関0.85超で「分散効果なし」警告
> - **ポートフォリオAI診断**: 保有全体＋ウォッチ銘柄＋地合い＋トレード日誌をAIが俯瞰し、健全度スコア・最大リスク・銘柄別アクション・売買のクセへの助言を返す
> - **トレード日誌**: 決済時に価格と理由を記録→実現損益・勝率・平均利益/損失・プロフィットファクターを自動集計。**成績は教訓生成とポートフォリオ診断に自動注入**(自分の売買のクセからもAIが学ぶ)
> - **アナリスト情報**: 目標株価(乖離%)・アナリスト評価・配当落ち日チップ
>
> **本アーキテクチャ(無料データ+Lambda+単一ファイルフロント)での拡張はここが上限。** これ以上は、リアルタイム板情報(有料データ契約)・自動売買(証券API+誤発注リスク)・オプション/信用分析(データ源なし)の領域で、費用対効果とリスクの判断が必要になる

> - **有望銘柄スクリーニング**: 日米主力65銘柄（日経35＋米国30）を学習済み重みで一括採点→上位15を発掘、ワンタップ追加

## 2. 短期分析ロジック（想定保有: 数日〜数週間）— テクニカル100点満点

日足データ（直近300営業日）から算出。5カテゴリの加点方式。

| カテゴリ | 配点 | 指標と採点基準 |
|---|---|---|
| ① トレンド | 25 | MA5/MA25/MA75。パーフェクトオーダー（5>25>75）=25点、5>25のみ=15点、下降配列=0点。ゴールデンクロス発生5営業日以内は+5ボーナス（上限25） |
| ② モメンタム | 25 | RSI(14): 50〜65=15点（上昇余地あり）、30以下=10点（反発候補）、70以上=5点（過熱）。MACDヒストグラムがマイナス→プラス転換3日以内=+10点 |
| ③ 出来高 | 20 | 直近5日平均出来高 ÷ 20日平均。1.5倍以上かつ株価上昇=20点、1.2倍以上=12点、通常=6点、閑散（0.7倍未満）=0点 |
| ④ 価格位置 | 15 | ボリンジャーバンド(20,2σ): ミッドバンド〜+1σ=15点（順行）、-2σ接触=10点（逆張り候補）、+2σ超=3点（過熱） |
| ⑤ 相対力 | 15 | 直近1ヶ月リターン − 指数リターン（日本株はTOPIX ^N225代替可、米株はS&P500 ^GSPC）。+5%以上=15点、0〜5%=10点、負け=0〜5点 |

**シグナル判定:**
- 70点以上 → 🟢 買い候補
- 45〜69点 → 🟡 中立・監視
- 45点未満 → 🔴 見送り／売り検討

各カテゴリの根拠を日本語テキストで返す（例:「MA5がMA25を3日前に上抜け（ゴールデンクロス）」）。

## 3. 長期分析ロジック（想定保有: 1年以上）— ファンダメンタルズ100点満点

yfinance の `info` / `financials` / `balance_sheet` / `cashflow` から算出。データ欠損時はそのカテゴリを按分除外して100点換算（欠損だらけの銘柄は「データ不足」表示）。

| カテゴリ | 配点 | 指標と採点基準 |
|---|---|---|
| ① 割安性 | 25 | PER: 15倍以下=10点、15〜25=6点、25超=2点（赤字=0点）。PBR: 1倍以下=8点、1〜2=5点。PEG(PER÷EPS成長率): 1以下=+7点 |
| ② 収益性 | 25 | ROE: 15%以上=12点、10〜15=8点、8〜10=4点。営業利益率: 15%以上=8点、10〜15=5点。ROA5%以上=+5点 |
| ③ 成長性 | 25 | 売上高3年CAGR: 10%以上=12点、5〜10=8点、0〜5=4点、マイナス=0点。EPS成長率も同様に最大13点 |
| ④ 財務健全性 | 15 | 自己資本比率: 50%以上=8点、30〜50=5点、30未満=2点。営業CFプラス継続=+4点、フリーCFプラス=+3点 |
| ⑤ 株主還元 | 10 | 配当利回り: 3%以上=5点、1.5〜3=3点。配当性向30〜60%の健全レンジ=+3点。自社株買い実績=+2点 |

**判定:** 70点以上=🟢 長期投資候補 / 50〜69=🟡 条件付き / 50未満=🔴 見送り

### 業種補正（Phase3）
PER/PBRは業種で水準が違うため、将来的にはウォッチリスト内の同業種中央値との相対評価に切り替える。v1は絶対値基準で開始。

## 4. 総合判定 — 短期×長期の4象限マトリクス

| | 長期スコア高（≥70） | 長期スコア低（<50） |
|---|---|---|
| **短期スコア高（≥70）** | ◎ 本命: 押し目を待たず打診買い候補 | △ 短期トレード限定（長期保有は非推奨） |
| **短期スコア低（<45）** | ○ 監視: 良い会社だが今は買い場でない → 押し目待ちリスト | × 見送り |

## 5. Lambda API 設計（mydesk-stock-analysis）

既存Lambdaと同じく Function URL + `x-mydesk-secret` ヘッダー認証。

```jsonc
// 単一銘柄分析
{ "action": "analyze", "ticker": "7203.T" }
→ { ticker, name, market, price, currency, updatedAt,
    short: { score, signal, breakdown: [{category, points, max, reason}] },
    long:  { score, signal, breakdown: [...], missing: ["PEG"] },
    quadrant: "本命" }

// ウォッチリスト一括（キャッシュ優先・最大30銘柄）
{ "action": "analyze-batch", "tickers": ["7203.T","AAPL","MSFT"] }

// 銘柄検索（ティッカー解決）
{ "action": "search", "query": "トヨタ" }

// （Phase3）AIコメント
{ "action": "ai-comment", "ticker": "7203.T" }  // Bedrock Claudeで3〜5行の日本語所見
```

- タイムアウト: analyze=30秒、analyze-batch=5分（reanalyzeAllと同様の運用）
- キャッシュ: S3 `mydesk-files-dustalk-1777302196/stock-cache/{ticker}.json`（株価15分・財務24時間のTTLをJSON内タイムスタンプで判定）

## 8. リスク・注意点

- **yfinanceは非公式**: Yahoo側仕様変更で壊れる可能性。Lambda内でtry/exceptしキャッシュフォールバック。恒久対策はJ-Quants（日本株）併用。
- **日本株の財務データ欠損**: 中小型株はROE等が取れないことがある → 欠損按分ルール（§3）で対応。
- **Lambdaコールドスタート**: yfinance+pandasでパッケージが重い（約60MB）→ Lambdaレイヤー化、メモリ1024MB推奨。
- **リアルタイム性**: Yahooの日本株は20分遅延。デイトレ用途ではなくスイング〜長期の判断ツールと位置づける。
