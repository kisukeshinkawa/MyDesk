■ 音源ファイルの置き場所(置くだけで自動で差し替わります)

このフォルダに以下の名前で音源(.wav / .mp3 / .ogg)を置くと、
内蔵シンセ音の代わりに再生されます。無いものはシンセ音のままです。

  bgm_menu    … タイトル/ホームのBGM(ループ)
  bgm_race    … レース中のBGM(ループ・控えめ音量)
  se_click    … ボタンのクリック音(0.1秒くらい)
  se_whoosh   … カットイン/技発動のスウィッシュ
  se_horn     … スタートホーン
  se_fanfare  … 勝利ファンファーレ
  se_cheer    … 歓声(2〜3秒)
  se_crowd    … 観客のざわめき(ループ)
  se_engine   … モーターのエンジン音(ループ)

Unityを開くと自動でインポートされ、Consoleの[音源チェック]に
読み込めたファイル数が表示されます。
